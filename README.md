# RetailShift Analytics

Frontend retail & store operations analytics dashboard built with **React**, **TypeScript**, and **@faker-js/faker** — inspired by real shift-supervision workflows (daily/monthly sales vs. targets, safe cash bundles & armored car pickups, monthly campaign goals, and customer delight ratings).

## Planned & Core Features
- **Shift Filtering:** Switch between *All*, *Morning*, *Afternoon*, and *Night* shifts.
- **Sales & Target Tracking:** Daily sales trend and progress toward the monthly store target.
- **Safe & Armored Car Control:** Tracking R$ 1,000 cash bundles in the safe and twice-weekly armored pickups.
- **Monthly Campaigns:** Unit progress bars for promotional products.
- **Customer Delight ("Encantou"):** Store and staff service rating overview.

## Tech Stack
- React + TypeScript + Vite
- `@faker-js/faker` for realistic mock operational data
- `lucide-react` for icons
